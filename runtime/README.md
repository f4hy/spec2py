# spec2py-runtime

The runtime library behind clients generated by
[spec2py](https://github.com/f4hy/spec2py). Generated code only describes
operations; everything that happens at request time lives here, so a fix
arrives with a dependency upgrade instead of a regeneration.

| Area | Behaviour |
| --- | --- |
| Transport | httpx2, with pluggable `transport=` / `http_client=` for tests and custom stacks |
| Retries | Exponential backoff with jitter. Honours `Retry-After`, `retry-after-ms` and `x-should-retry`. Retries idempotent methods, and POSTs once an idempotency key is attached (generated automatically when the API declares an idempotency header). |
| Auth | `ApiKeyAuth` (header, query or cookie), `BearerAuth`, `BasicAuth`, `OAuth2ClientCredentials` (fetch, cache, refresh, retry on 401), `MultiAuth`, or any `httpx2.Auth` |
| Pagination | `CursorPagination`, `OffsetPagination`, `PageNumberPagination`, `LinkHeaderPagination`; `Page` / `AsyncPage` / `AsyncPaginator` iterate lazily and expose `.data` and `.next_cursor` |
| Streaming | SSE and NDJSON decoded into typed events (`Stream`, `AsyncStream`) |
| Uploads | Multipart from file objects, paths, bytes or `(name, content, type)` tuples |
| Errors | `APIError` → `APIStatusError` → `NotFoundError`, `RateLimitError`, ...; bodies parsed into declared models |
| Observability | `Hooks(on_request=..., on_response=...)` and OpenTelemetry spans when `opentelemetry-api` is installed (`pip install spec2py-runtime[otel]`) |
| Models | `BaseModel` with lenient parsing, `Tolerant` enums, lazy validator builds |

Requires Python 3.14.
